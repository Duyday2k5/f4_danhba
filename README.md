# f4_danhba

Ứng dụng quản lý danh bạ mini (Lab F4) bằng Flutter.

## Các tính năng nâng cao (Đã thực hiện)

* **NC1 - Tìm kiếm liên hệ:** Thêm màn hình tìm kiếm, lọc trực tiếp theo tên/số điện thoại. Trả đối tượng `Contact` đã chọn về màn hình trước đó để mở tiếp màn hình Chi tiết.
* **NC2 - Hero Animation:** Sử dụng widget `Hero` (tag là số điện thoại) cho avatar, tạo hiệu ứng chuyển cảnh mượt mà giữa màn hình Danh sách/Tìm kiếm và màn hình Chi tiết.
